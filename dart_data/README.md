# DART 보고서 업로드 폴더

DART에서 다운받은 공시 원문 zip 파일을 이 폴더에 올려두세요.

## 올리는 방법 (GitHub 웹에서)

1. GitHub에서 이 폴더(`dart_data`)를 연다
2. 우측 상단 **Add file → Upload files** 클릭
3. zip 파일들을 드래그해서 놓고 **Commit changes**
   - 여러 개 한꺼번에 가능 (파일당 25MB 제한)
   - 회사별로 하위 폴더를 만들어도 됨 (예: `dart_data/케이에스피/`)

## 요청하는 방법

Claude 세션에서 예를 들어 이렇게 요청:

- "dart_data 폴더에 올려둔 보고서로 부문별 실적 분기별로 정리해줘"
- "dart_data/케이에스피 폴더 확인해서 수주상황만 엑셀로 뽑아줘"

결과 엑셀은 채팅으로 보내거나 `결과물/` 폴더에 커밋해 드립니다.
