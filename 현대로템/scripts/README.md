# 현대로템 단일판매·공급계약 매출인식 추출 스크립트

각 정기보고서(DART 원본 XML, `현대로템/*.zip`)의
「XI. 그 밖에 투자자 보호를 위하여 필요한 사항 → 1. 공시내용 진행 및 변경사항 →
나. 단일판매·공급계약 공시 관련 진행 사항 (1)」 표를 파싱해
계약별·분기별 매출인식으로 정리합니다.

## 파이프라인
1. `1_parse_reports.py`  — zip 내 보고서 XML에서 해당 표를 찾아 파싱(인코딩 자동감지, rowspan 처리, 2026Q1 신형식 대응)
2. `2_build_dataset.py`  — 신고일자 기준으로 계약 통합, '당기(YTD)' 차분으로 달력분기 매출인식 계산 → `dataset.json`
3. `3_make_xlsx.py`      — 분류(철도/방산/기타·국내/국외·국가) 부여 후 최종 엑셀 생성

## 데이터 범위
- 이 표는 2024 사업보고서(FY2024)부터 신설. 데이터 존재 보고서 5개:
  2024사업 · 2025반기 · 2025.3Q · 2025사업 · 2026.1Q
- 2025.1Q 분기보고서는 표 생략(반기·사업에만 기재) → 2025 상반기 합산 제공

## 새 분기 추가 시
1. `현대로템/`에 새 보고서 zip 추가
2. 스크립트 상단 REPORTS/PERIODS 목록에 항목 추가 후 순서대로 실행

> 참고: 스크립트 상단의 파일 경로는 생성 당시 작업 디렉터리를 가리키므로,
> 다른 환경에서 실행할 때는 경로를 알맞게 수정하세요. 최종 산출물
> `현대로템_분기별_단일판매공급계약_매출인식.xlsx` 는 이미 값이 채워진 완성본입니다.
